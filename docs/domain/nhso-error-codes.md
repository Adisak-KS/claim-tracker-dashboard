# รหัสข้อผิดพลาด (Error Code) ของ สปสช.

> **ที่มา:** API Specification 13Plus for NHSO Digital Platform v1.3.5.1-draft

> **ตรวจสอบและคัดลอกเมื่อ:** 2026-09-12

มีทั้งหมด **654 รหัส** แต่ละรหัสมีข้อความอธิบาย วิธีแก้ และธง AllowClaim

## ธง AllowClaim สำคัญที่สุด

สปสช. ระบุมาให้ว่าแต่ละรหัสยังส่งเบิกต่อได้หรือไม่

| ค่า | ความหมาย | ผลกับหน่วยบริการ |
|---|---|---|
| `Y` | ส่งเบิกได้ | แก้ข้อมูลแล้วส่งใหม่ได้ ยังมีโอกาสได้เงิน |
| `N` | ไม่ให้ส่งเบิก | รายการนี้จบ ต้องอุทธรณ์หรือปล่อย |

จากทั้งหมด 654 รหัส มี **21 รหัสที่ยังส่งเบิกได้**
และ **524 รหัสที่ส่งไม่ได้แล้ว**

> 🔴 **หน้าจอต้องแยก 2 อย่างนี้ให้ชัด** เพราะความหมายทางธุรกิจต่างกันสิ้นเชิง
> รายการที่ AllowClaim = N คือ **เงินที่หายไปแล้ว** ไม่ใช่งานที่รอแก้

## วิธีใช้ในระบบ

1. **หน้าภาพรวม** แสดงกลุ่มใหญ่ 5 อันดับแรก ผู้บริหารเห็นว่าปัญหากองอยู่หมวดไหน
2. **หน้าปัญหา** กดเข้ากลุ่มแล้วเห็นรหัสย่อยพร้อมวิธีแก้ ทีมฝึกอบรมเอาไปสอน รพ. ได้เลย
3. **แยกตามธง AllowClaim** เพราะรายการที่ส่งไม่ได้แล้วคือเงินที่หาย ต้องรายงานแยก
