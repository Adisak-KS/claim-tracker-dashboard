# รหัสสถานะรายการ (Status Code) ของ สปสช.

> **ที่มา:** API Specification 13Plus for NHSO Digital Platform v1.3.5.1-draft
> ภาคผนวก 1 (Status Code) หน้า 39-43 · ฉบับลงวันที่ 08/9/2569
> **ตรวจสอบและคัดลอกเมื่อ:** 2026-09-12

รหัสสถานะบอกว่ารายการเคลมเดินทางไปถึงขั้นไหนแล้ว มีทั้งหมด 66 รหัส

ใช้ตอบคำถามที่ผู้บริหารถามบ่อยที่สุด: **"เงินที่ส่งเบิกไปค้างอยู่ตรงไหน"**
ไม่ใช่แค่ "ส่งผ่านหรือไม่ผ่าน"

## เส้นทางปกติของรายการที่ผ่านฉลุย

```
F000 กำลังนำเข้าไฟล์
  -> 1100 รอส่งเบิก
  -> 1103 ส่งเบิกแล้ว
  -> 2000 รอประมวลผลโดย สปสช.
  -> 4000 อยู่ระหว่างกระบวนการ Audit
  -> 5000 รอจ่ายเงิน
  -> 5005 โอนเงินเรียบร้อย
```

## แบ่งตามขั้นตอน

| ขึ้นต้นด้วย | ขั้นตอน | ความหมาย |
|---|---|---|
| `F` | ขั้นนำเข้าไฟล์ | ระบบกำลังรับไฟล์และตรวจความสมบูรณ์เบื้องต้น |
| `1` | ขั้นตรวจสอบและส่งเบิก | ตรวจ validation แล้วส่งเบิกเข้า สปสช. |
| `2` | ขั้นรอ สปสช. ประมวลผล | สปสช. รับเรื่องแล้ว กำลังตรวจตามประกาศ |
| `3` | ขั้นไม่ผ่านประมวลผล | ไม่ผ่านเงื่อนไข ต้องแก้แล้วส่งใหม่ |
| `4` | ขั้นตรวจสอบ (Audit) | ทีม Audit ตรวจความผิดปกติ |
| `5` | ขั้นจ่ายเงิน | รอจ่าย กำลังโอน หรือโอนเรียบร้อย |
| `6` | ขั้นไม่อนุมัติจ่าย | สปสช. ไม่อนุมัติ อุทธรณ์ได้ |
| `7` | ขั้นอุทธรณ์ | ยื่นอุทธรณ์หรือยกเลิกแล้วส่งใหม่ |

## รายการรหัสทั้งหมด

### ขั้นนำเข้าไฟล์ (`F`)

| รหัส | ความหมาย |
|---|---|
| `F000` | กำลังนำเข้าไฟล์ ระบบกำลังนำเข้าไฟล์ |
| `F001` | กำลังตรวจสอบขั้นต้น กำลังนำไฟล์มาตรวจสอบความเชื่อมโยง / ตรวจสอบเงื่อนไข ความสมบูรณ์ และเงื่อนไขตามประกาศเบื้องต้นที่สามารถ ตรวจสอบได้ |
| `F002` | ตรวจสอบขั้นต้นเสร็จสิ้น ระบบประมวลผลไฟล์ทั้งหมดเสร็จสิ้นแล้ว สามารถตรวจสอบ ระดับรายการได้ |
| `F100` | นำเข้าไม่สำเร็จ บางไฟล์ไม่สามารถนำเข้าได้ทั้งไฟล์ ทำให้ถือว่าทั้งชุดของไฟล์ ไม่สมบูรณ์ ต้องดำเนินการอัปโหลด และเริ่มกระบวนการใหม่ ทั้งหมด |
| `F200` | ขอยกเลิกไฟล์ ไฟล์ที่ตรวจสอบขั้นต้นเสร็จสิ้น แต่หน่วยงานได้มีการขอ ยกเลิก (รายการย่อยภายในต้องยังไม่ถูกส่งเบิก) |
| `F020` | กำลังนำเข้าข้อมูล ระบบกำลังนำเข้าไฟล์ |
| `F201` | นำเข้าสำเร็จ เมื่อนําเข้าข้อมูลสําเร็จทั้งหมดแล้ว และรายการในแฟ้มนั้นๆ นําเข้าสําเร็จทุกรายการ |
| `F202` | นำเข้าสำเร็จบางส่วน เมื่อนำเข้าข้อมูลสำเร็จทั้งหมดแล้ว และพบว่ามีบางรายการ ในแฟ้มนั้นๆนำเข้าสำเร็จอย่างน้อย 1 รายการ และพบบาง รายการเกิดข้อผิดพลาดอย่างน้อย 1 รายการ |
| `F203` | นำเข้าไม่สำเร็จ เมื่อพบว่าทุกรายการในแฟ้มนั้นๆ นำเข้าไม่สำเร็จทุกรายการ |
| `F204` | ไม่อัปโหลด ไม่ได้นำเข้าข้อมูลแฟ้มนั้นๆ |

### ขั้นตรวจสอบและส่งเบิก (`1`)

| รหัส | ความหมาย |
|---|---|
| `1000` | กำลังตรวจสอบขั้นต้น การตรวจสอบขั้นต้นของรายการที่ส่งผ่านรูปแบบ API โดย ตรวจสอบความเชื่อมโยง / ตรวจสอบเงื่อนไขความสมบูรณ์ และเงื่อนไขตามประกาศเบื้องต้นที่สามารถตรวจสอบได้ |
| `1100` | รอส่งเบิก สถานะของรายการที่ผ่านการตรวจสอบขั้นต้น โดยผ่าน Validatation ทั้งหมด |
| `1101` | ไม่ผ่านการตรวจสอบขั้นต้น สถานะของรายการไม่ผ่านการ Validatation ขั้นต้น - มี Flag กำกับว่าอนุญาตให้ส่งรายการไปเบิกต่อได้หรือไม่ |
| `1102` | ส่งเบิกไม่สำเร็จ สถานะของรายการที่ี่พบว่ามีการส่งเบิกซ้ำ |
| `1103` | ส่งเบิกแล้ว รายการที่ส่งเบิกผ่านแล้ว |
| `1104` | กำลังส่งเบิก สถานะอยู่ในช่วงดำเนินการประมวลการส่งเบิก (Async Submit) |

| `2100` | รอชี้แจงการ Authen สถานะกรณีไม่พบรายการ Authen (สำหรับบริการ/เงื่อนไข ที่ต้องใช้) |
| `2101` | รอพิจารณาการชี้แจง Authen กรณีหน่วยบริการชี้แจงการ Authen เข้ามาแล้ว และรอ ทีมสปสช. อนุมัติคำขอ Waive Authen นั้น |

| `2202` | สปสช. ทบทวนการอนุมัติ OP Refer สถานะเมื่อหน่วยบริการส่งเบิก ขอชี้แจงรายการเข้ามา เรียบร้อยแล้ว และอยู่ระหว่างรอ สปสช. พิจารณา |
| `2300` | รอประมวลผลโดย สปสช. ผ่าน Basic Validation แล้ว เป็นรายการที่ผ่านการตรวจสอบ C Validate เรียบร้อยแล้ว รอตรวจเงื่อนไขตามประกาศ |

## ข้อควรระวัง

- **`5102` ไม่ใช่ "ตีกลับ" ทั่วไป** แต่เจาะจงว่าไม่ตรงเงื่อนไขสิทธิ 4 แบบ
  (OFC ข้าราชการ · LGO ท้องถิ่น · BKK กรุงเทพ · UCS บัตรทอง)
  อย่าเขียนป้ายกำกับในหน้าจอว่า "ตีกลับ" เฉย ๆ เพราะผู้ใช้จะหาสาเหตุไม่เจอ
- รหัสขึ้นต้น `F` ใช้กับ **การนำเข้าทั้งไฟล์** ส่วนรหัสตัวเลขใช้กับ **รายการเดี่ยว**
  คนละระดับกัน อย่าเอามานับรวมกัน
- สถานะที่ลงท้ายด้วยการ "ส่งใหม่แล้ว" (`3102`, `4104`, `5101`, `5008`, `7200`)
  หมายถึงรายการเดิมถูกแทนที่แล้ว **ห้ามนับซ้ำกับรายการใหม่**
