# ขั้นตอนการส่งเคลม (สำหรับคนที่ไม่ได้ทำงานสายนี้)

เอกสารนี้อธิบายว่า "ส่งเคลม" คืออะไร เพื่อให้คนที่มาทำระบบเข้าใจว่า
ตัวเลขบนหน้าจอมาจากไหนและทำไมถึงสำคัญ

## เรื่องย่อ

เวลาคนไข้ใช้สิทธิบัตรทองไปรักษาที่โรงพยาบาล **โรงพยาบาลออกเงินไปก่อน**
แล้วค่อยตั้งเรื่องเบิกคืนจาก สปสช. ทีหลัง

"ส่งเคลม" คือขั้นตอนตั้งเรื่องเบิกนี้

ถ้าส่งไม่สำเร็จหรือถูกตีกลับแล้วไม่มีใครตามแก้ **โรงพยาบาลไม่ได้เงินคืน**
นี่คือเหตุผลที่ระบบติดตามนี้มีความหมาย

## ขั้นตอนทั้งหมด

```
คนไข้มารักษา
   |
   v
โรงพยาบาลบันทึกข้อมูลใน HOSxP / EHP / NHIP
   |
   v
ระบบดึงข้อมูล แปลงเป็น "13 แฟ้ม" ตามรูปแบบที่ สปสช. กำหนด
   |
   v
ตรวจสอบก่อนส่ง (ข้อมูลครบไหม)
   |
   v
ส่งผ่าน API ไป สปสช.        <-- ตรงนี้คือจุดที่ระบบเราเก็บข้อมูล
   |
   v
สปสช. ตรวจสอบตามประกาศ
   |
   v
อนุมัติ แล้วโอนเงินคืนโรงพยาบาล
```

## 13 แฟ้มคืออะไร

สปสช. กำหนดให้ส่งข้อมูลการรักษา 1 ครั้ง แยกเป็น 13 แฟ้ม แต่ละแฟ้มเก็บคนละเรื่อง

| แฟ้ม | เก็บอะไร |
|---|---|
| OPD | การมารับบริการผู้ป่วยนอก |
| Patient | ข้อมูลผู้ป่วย |
| Provider | หน่วยบริการ |
| Practitioner | ผู้ให้การรักษา |
| Diagnosis | การวินิจฉัยโรค |
| CHA / CHAD | ค่าใช้จ่าย และรายละเอียดค่าใช้จ่าย |
| Procedure | หัตถการ |
| AER | อุบัติเหตุฉุกเฉิน |
| CMHS | สุขภาพจิต |
| Disability | ความพิการ |
| Newborn | ทารกแรกเกิด |
| Prenatal | ฝากครรภ์ |

**ระบบเราไม่เก็บเนื้อหาใน 13 แฟ้ม** เก็บแค่ว่าส่งสำเร็จไหม ติดปัญหารหัสอะไร
เพราะในนั้นมีข้อมูลส่วนตัวผู้ป่วยเต็มไปหมด

## สองกองทุน

| | NHSO | FDH |
|---|---|---|
| คือ | บัตรทองหลัก | ผู้สูงอายุและผู้พิการ |
| ตารางฝั่ง HOSxP | `eclaim_fee_schedule` | `fdh_fee_schedule` |
| การตรวจสอบ | เข้มกว่า | เบากว่า |

ระบบเราต้องแยกรายงาน 2 กองทุนนี้ได้ เพราะเงื่อนไขคนละชุด

## สถานะที่ต้องเข้าใจ

มีสถานะ 2 ชั้น คนละเรื่องกัน **อย่าเอามาปนกัน**

### ชั้นที่ 1: ฝั่งโรงพยาบาล (ส่งออกไปได้ไหม)

| ค่า | ความหมาย |
|---|---|
| `Y` | ส่งสำเร็จ |
| `N` | ส่งไม่สำเร็จ |
| ว่าง | ยังไม่เคยส่ง |
| `C` | ยกเลิกแล้ว |

### ชั้นที่ 2: ฝั่ง สปสช. (รับแล้วประมวลผลถึงไหน)

รหัส 66 ตัว ตั้งแต่ `F000` กำลังนำเข้าไฟล์ ไปจนถึง `5005` โอนเงินเรียบร้อย
ดูรายละเอียดที่ [nhso-status-codes](nhso-status-codes.md)

**ส่งสำเร็จ ไม่ได้แปลว่าได้เงิน** ส่งสำเร็จแปลว่า สปสช. รับเรื่องแล้วเท่านั้น
กว่าจะได้เงินต้องผ่านการประมวลผล การ Audit และรอบจ่ายเงินอีก

นี่คือเหตุผลที่แดชบอร์ดต้องแสดงทั้ง 2 ชั้น ไม่ใช่แค่ "ส่งผ่านกี่ %"

## คำที่เจอบ่อย

| คำ | แปลว่า |
|---|---|
| VN | เลขที่การมารับบริการผู้ป่วยนอก (1 ครั้งที่มาหาหมอ) |
| AN | เลขที่การนอนโรงพยาบาล |
| HN | เลขประจำตัวผู้ป่วยของโรงพยาบาลนั้น (ผูกทุกครั้งที่มา) |
| Authen Code | รหัสยืนยันสิทธิที่ต้องขอจาก สปสช. |
| REP | รายงานผลการจ่ายเงินจาก สปสช. |
| งวด | รอบการจ่ายเงิน |
| ตีกลับ | สปสช. ไม่รับ ต้องแก้แล้วส่งใหม่ |
