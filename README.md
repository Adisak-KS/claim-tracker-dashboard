# ระบบติดตามการส่งเคลม

เว็บติดตามสถานะการส่งเคลมของหน่วยบริการในเครือข่าย BMS
ผู้ใช้คือผู้บริหาร ผู้จัดการ PM ทีมฝึกอบรม และผู้ดูแลระบบ

> **สถานะ: Phase 1 หน้าจอกับข้อมูลจำลองเท่านั้น**
> ยังไม่มี backend จริง ยังไม่ต่อฐานข้อมูล
> 🔴 ตัวเลขทุกตัวบนหน้าจอเป็นข้อมูลสมมติ ไม่ใช่ของหน่วยบริการจริง

## หน้าจอที่มี

| หน้า | ตอบคำถามอะไร |
|---|---|
| ภาพรวม | ทั้งประเทศส่งเคลมเป็นอย่างไร |
| หน่วยบริการ | ตอนนี้มีรายการอะไรเข้ามา และหน่วยไหนมีปัญหาสะสม |
| ปัญหา | ปัญหาอะไรพบมากที่สุด และแก้อย่างไร |
| รายงาน | สรุปสำหรับนำเสนอ |

## เริ่มพัฒนา

```bash
cd frontend
npm install
npm run dev
```

เปิดที่ http://localhost:3000

## ก่อนบอกว่าเสร็จ

```bash
cd frontend
npx tsc --noEmit   # ต้องไม่มี error
npm run lint       # ต้องไม่มี error
```

แล้วเปิดดูหน้าจอจริงในเบราว์เซอร์ตามเส้นทางที่ผู้ใช้กดถึง
รายละเอียดกติกาทั้งหมดอยู่ใน [CLAUDE.md](CLAUDE.md)

## build เป็นไฟล์นิ่ง

ใช้ตอนเอาขึ้น GitHub Pages ให้คนอื่นดูหน้าตา

```bash
cd frontend
node scripts/build-pages.mjs
```

ได้ผลใน `frontend/out/`

🔴 **โหมดนี้ใช้โชว์หน้าตาเท่านั้น** ข้อมูลถูกสร้างในเครื่องผู้ใช้ ไม่ได้มาจากเซิร์ฟเวอร์
และสร้างหน้ารายละเอียดหน่วยบริการไว้ 150 แห่งที่มีลิงก์ชี้ถึงจริง ไม่ใช่ครบทั้ง 5,013 แห่ง
